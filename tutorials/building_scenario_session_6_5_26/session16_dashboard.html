Where TWTL Fits

Rule Priority (from last session)

  • P0 — Safety: Never collide. Expressed as HT ¬πcollision
  • P1 — Legal compliance: Obey signals. HT πgreen · stop on red
  • P2 — Soft preferences: Comfort, speed, efficiency (AGM robustness)

Each scenario is designed to stress-test one level of this hierarchy. Go to the TWTL Formulas tab for all four formal specifications.

SCENARIO 1
Green Light — Clear Intersection

Purpose

  • Establishes the simplest baseline: planner should drive straight through without hesitation
  • Validates basic CARLA setup: ego spawn, light detection, waypoint tracking
  • Any planner that fails here has fundamental navigation issues

Actors Required

Ego Vehicle (Tesla Model 3) Traffic Light → GREEN
  • Ego spawns 40m before stop line
  • Facing the intersection (0° or 90° yaw)
  • No other vehicles or pedestrians
  • Light forced to GREEN for full scenario

Expected Planner Behavior

  • Approach at normal speed (≤ speed limit)
  • Detect GREEN light via semantic sensor
  • No deceleration required for intersection
  • Pass through center of intersection
  • Continue for 30m on the far side
  • Zero violations of any TWTL rule
TWTL Specification — Scenario 1
φ₁ = [ H₂ πintersection ][0,15] ∧ HT ¬πcollision ∧ HT πgreen_ok
// Read: "Within 15 seconds, pass through the intersection (stay 2 steps);
// AND never collide; AND only proceed when light is green"
// Robustness ρ₁ > 0 ↔ scenario passed ✓

# Scenario 1: Green Light, Clear Intersection
# Purpose: Verify planner proceeds through green light without hesitation
# Expected: Ego passes through; ρ(φ₁) > 0

import carla
import time
import numpy as np

def setup_scenario_1(client, world):
    """Set up Scenario 1: Green light, clear intersection."""

    carla_map = world.get_map()
    blueprint_library = world.get_blueprint_library()

    # ── 1. Spawn ego vehicle ─────────────────────────────────────
    ego_bp = blueprint_library.find('vehicle.tesla.model3')
    ego_bp.set_attribute('color', '255,255,255')   # white for visibility

    # 40m south of intersection center, facing north (yaw=90)
    ego_transform = carla.Transform(
        carla.Location(x=0.0, y=-40.0, z=0.5),
        carla.Rotation(yaw=90.0)
    )

    # Use nearest safe spawn point to avoid spawning inside geometry
    spawn_points = carla_map.get_spawn_points()
    ego_transform = find_nearest_spawn(spawn_points, ego_transform.location)

    ego = world.spawn_actor(ego_bp, ego_transform)
    print(f"[S1] Ego spawned at {ego.get_location()}")

    # ── 2. Find and configure traffic lights ─────────────────────
    traffic_light = find_facing_light(world, ego.get_location())

    if traffic_light:
        traffic_light.set_state(carla.TrafficLightState.Green)
        traffic_light.freeze(True)      # prevent light from changing state
        traffic_light.set_green_time(60.0)
        print(f"[S1] Traffic light → GREEN (frozen)")
    else:
        print("[S1] WARNING: No traffic light found, check intersection location")

    # ── 3. Attach overhead camera ────────────────────────────────
    camera = attach_overhead_camera(world, ego, blueprint_library)

    return ego, traffic_light, camera


def find_nearest_spawn(spawn_points, target_location):
    """Find closest spawn point to a target location."""
    nearest = None
    min_dist = float('inf')

    for sp in spawn_points:
        dist = sp.location.distance(target_location)
        if dist < min_dist:
            min_dist = dist
            nearest = sp

    print(f"[S1] Nearest spawn: {nearest.location} (dist={min_dist:.1f}m)")
    return nearest


def find_facing_light(world, ego_location, search_radius=60.0):
    """Find the traffic light most likely facing the ego vehicle."""
    traffic_lights = world.get_actors().filter('traffic.traffic_light')

    nearest_light = None
    min_dist = float('inf')

    for light in traffic_lights:
        dist = light.get_location().distance(ego_location)
        if dist < search_radius and dist < min_dist:
            min_dist = dist
            nearest_light = light

    if nearest_light:
        print(f"[S1] Found traffic light {nearest_light.id} at dist={min_dist:.1f}m")
    return nearest_light


def attach_overhead_camera(world, vehicle, blueprint_library, height=25.0):
    """Attach a bird's-eye camera above the vehicle."""
    cam_bp = blueprint_library.find('sensor.camera.rgb')
    cam_bp.set_attribute('image_size_x', '1280')
    cam_bp.set_attribute('image_size_y', '720')
    cam_bp.set_attribute('fov', '90')

    cam_transform = carla.Transform(
        carla.Location(x=0.0, z=height),
        carla.Rotation(pitch=-90.0)     # looking straight down
    )
    camera = world.spawn_actor(cam_bp, cam_transform, attach_to=vehicle)
    camera.listen(lambda img: img.save_to_disk(f'output/s1_{img.frame:06d}.png'))
    print(f"[S1] Overhead camera attached at z={height}m")
    return camera


def run_scenario_1():
    """Main entry point for Scenario 1."""
    client = carla.Client('localhost', 2000)
    client.set_timeout(20.0)

    print("[S1] Loading Town05...")
    world = client.load_world('Town05')
    world.set_weather(carla.WeatherParameters.ClearNoon)

    # Synchronous mode for deterministic timing
    settings = world.get_settings()
    settings.synchronous_mode = True
    settings.fixed_delta_seconds = 0.05   # 20 Hz
    world.apply_settings(settings)

    ego, light, camera = None, None, None

    try:
        ego, light, camera = setup_scenario_1(client, world)

        # Enable ego autopilot (or hook your hierarchical planner here)
        ego.set_autopilot(True)

        print("[S1] Running for 15 seconds — watch ego cross intersection...")
        for tick in range(300):    # 300 ticks × 0.05s = 15 seconds
            world.tick()

            if tick % 20 == 0:      # print status every 1 second
                loc = ego.get_location()
                vel = ego.get_velocity()
                speed = (vel.x**2 + vel.y**2)**0.5 * 3.6    # km/h
                print(f"  t={tick*0.05:.1f}s | pos=({loc.x:.1f},{loc.y:.1f}) | speed={speed:.1f} km/h")

        print("[S1] Scenario complete. Check output/ for screenshots.")

    finally:
        # Always clean up actors
        if camera: camera.destroy()
        if ego:    ego.destroy()

        # Restore async mode
        settings = world.get_settings()
        settings.synchronous_mode = False
        world.apply_settings(settings)
        print("[S1] Cleaned up.")


if __name__ == '__main__':
    run_scenario_1()
SCENARIO 2
Yellow Light — Decision Point

Purpose

  • Tests the planner's stop-or-go decision under a yellow light
  • The TWTL formula must capture the dilemma zone: if close enough, proceed; if far, stop
  • Uses AGM robustness (η) because the decision is about smooth tradeoffs, not hard cutoffs

Actors Required

Ego Vehicle Traffic Light → YELLOW
  • Ego spawns 25m before stop line (dilemma zone)
  • Initial speed: ~30 km/h
  • Light switches to YELLOW at t=0
  • Light turns RED after 3 seconds

Expected Planner Behavior

  • Compute stopping distance: d = v²/2a
  • If d > distance to stop line → proceed
  • If d ≤ distance to stop line → brake hard
  • At 30 km/h and a = 3 m/s² → d ≈ 12m
  • So at 25m: should brake and stop
  • No entry into intersection during RED
TWTL Specification — Scenario 2
φ₂ = (d > d_stop → [ H₃ πstopped ][0,5]) ∧ (d ≤ d_stop → [ H₁ πthrough ][0,4]) ∧ HT ¬πcollision ∧ HT ¬πred_violation
// d = distance to stop line at moment light turns yellow
// d_stop = stopping distance given current speed
// Case 1 (d > d_stop): stop within 5 seconds for 3 seconds
// Case 2 (d ≤ d_stop): clear intersection within 4 seconds
// Always: no collision, no running red

def setup_yellow_light_sequence(world, light):
    """
    Trigger a yellow → red sequence at t=0.
    CARLA doesn't expose timing directly, so we force states manually.
    """
    # Step 1: Set light to yellow immediately
    light.set_state(carla.TrafficLightState.Yellow)
    light.set_yellow_time(3.0)   # 3 second yellow phase
    light.freeze(False)           # allow it to cycle normally
    print("[S2] Traffic light → YELLOW (3s), then RED")


def compute_stop_or_go(ego, stop_line_y):
    """Decide: should ego stop or proceed through yellow?"""
    import math

    velocity = ego.get_velocity()
    speed_ms = math.sqrt(velocity.x**2 + velocity.y**2)   # m/s
    location = ego.get_location()

    distance_to_line = abs(stop_line_y - location.y)

    # Stopping distance: d = v² / (2a), using comfortable decel a=3 m/s²
    deceleration = 3.0
    stopping_distance = (speed_ms**2) / (2 * deceleration)

    decision = "GO" if stopping_distance > distance_to_line else "STOP"

    print(f"[S2] speed={speed_ms*3.6:.1f} km/h | "
          f"dist_to_line={distance_to_line:.1f}m | "
          f"stop_dist={stopping_distance:.1f}m | "
          f"decision={decision}")

    return decision, stopping_distance, distance_to_line


def compute_yellow_robustness(trajectory, stop_line_y, light_history):
    """
    Compute TWTL robustness for Scenario 2.
    ρ > 0 if planner made correct decision and didn't run red.
    """
    red_violations = []
    comfort_values = []

    for i, state in enumerate(trajectory):
        location, velocity, light_state = state

        speed_ms = (velocity.x**2 + velocity.y**2)**0.5
        in_intersection = abs(location.y) < 10.0   # within 10m of center

        # Rule: no RED violation (in intersection during red = bad)
        if light_state == 'red' and in_intersection:
            red_violations.append(-1.0)
        else:
            red_violations.append(1.0)

    # ρ = min over all time steps (worst case wins)
    rho = min(red_violations)

    print(f"[S2] TWTL Robustness ρ = {rho:.3f}")
    print(f"[S2] {'PASSED ✓' if rho > 0 else 'FAILED ✗'}")
    return rho
SCENARIO 3
Red Light — Waiting Traffic

Purpose

  • Tests safe distance following and red-light compliance simultaneously
  • The planner must stop behind two vehicles, not just before the stop line
  • Validates the P0 (safety) and P1 (legal) layers of the hierarchy interact correctly

Actors Required

Ego Vehicle NPC Vehicle 1 (stopped at line) NPC Vehicle 2 (behind NPC 1) Traffic Light → RED
  • NPC 1: stopped at stop line (y = -3m)
  • NPC 2: stopped 8m behind NPC 1 (y = -11m)
  • Ego spawns 45m back (y = -45m)
  • Light held RED for full scenario (30s)

Expected Planner Behavior

  • Detect vehicles ahead using LiDAR / depth
  • Apply 2-second-rule following distance
  • Stop ≥ 5m behind NPC 2 (at approx y = -18m)
  • Maintain stop for full RED duration
  • Never enter intersection during RED
  • Zero collision events throughout
TWTL Specification — Scenario 3
φ₃ = HT ¬πcollision ∧ HT ¬πred_entry ∧ [ H₅ πstopped ][0,30]
// Always: no collision (P0 — safety)
// Always: never enter intersection while light is RED (P1 — legal)
// Within 30s: come to full stop (v < 0.5 m/s) and hold 5 time steps
// All three must hold simultaneously (conjunction)

def spawn_waiting_traffic(world, blueprint_library):
    """
    Spawn two stationary NPC vehicles queued at red light.
    Returns list of spawned actors for cleanup.
    """
    vehicles = []

    # Vehicle blueprints for traffic variety
    car_bps = [
        blueprint_library.find('vehicle.audi.a2'),
        blueprint_library.find('vehicle.nissan.micra'),
    ]

    # NPC 1 — stopped at stop line, 3m before intersection center
    npc1_transform = carla.Transform(
        carla.Location(x=0.0, y=-3.0, z=0.5),
        carla.Rotation(yaw=90.0)
    )

    # NPC 2 — stopped 8m behind NPC 1 (typical car length 4m + gap 4m)
    npc2_transform = carla.Transform(
        carla.Location(x=0.0, y=-11.0, z=0.5),
        carla.Rotation(yaw=90.0)
    )

    for i, (bp, transform) in enumerate(zip(car_bps, [npc1_transform, npc2_transform])):
        try:
            npc = world.spawn_actor(bp, transform)
            # Disable physics so NPC stays perfectly stationary
            npc.set_simulate_physics(False)
            vehicles.append(npc)
            print(f"[S3] NPC {i+1} spawned at {npc.get_location()}")
        except RuntimeError as e:
            print(f"[S3] Could not spawn NPC {i+1}: {e}")

    return vehicles


def monitor_safe_following(ego, npcs, carla_map):
    """
    Monitor: does ego maintain 2-second following distance?
    Returns robustness value (positive = safe, negative = violation).
    """
    ego_loc = ego.get_location()
    ego_vel = ego.get_velocity()
    ego_speed = (ego_vel.x**2 + ego_vel.y**2)**0.5

    # Find closest NPC ahead
    min_dist = float('inf')
    for npc in npcs:
        dist = ego_loc.distance(npc.get_location())
        if dist < min_dist:
            min_dist = dist

    # 2-second rule: required distance = 2s × speed + 2m buffer
    required_dist = 2.0 * ego_speed + 2.0

    # Robustness: positive means we have enough margin
    robustness = min_dist - required_dist

    return robustness, min_dist, required_dist
SCENARIO 4
Blocked Intersection — Pedestrians Crossing

Purpose

  • Most complex scenario — tests whether P0 (safety) overrides P1 (green light)
  • The light is green, but pedestrians are crossing: planner must yield
  • Directly validates the lexicographic priority of the TWTL rulebook

Actors Required

Ego Vehicle Traffic Light → GREEN Pedestrian 1 Pedestrian 2 Pedestrian 3
  • 3 pedestrians crossing at crosswalk (perpendicular)
  • Ped 1 starts at (−5, 0), walks east (+x direction)
  • Ped 2 starts at (−3, 0), 2-second delay
  • Ped 3 starts at (−1, 0), 4-second delay
  • Ego starts 40m back, same as Scenario 1

Expected Planner Behavior

  • Approach at normal speed (green light seen)
  • Detect pedestrians via semantic segmentation
  • Begin braking at ≥ 15m from crosswalk
  • Stop completely before crosswalk (y ≈ -8)
  • Wait until all pedestrians have cleared
  • Resume after pedestrian path is clear
TWTL Specification — Scenario 4
φ₄ = HT ¬πped_collision ∧ [H₃ πped_clear][0,∞] · [H₁ πthrough][0,10] ∧ HT ¬πcollision
// P0 (Safety): NEVER hit a pedestrian — takes priority over all other rules
// P1 (Legal+Safe): Wait until pedestrians have cleared crosswalk (3 steps),
// then proceed through intersection within 10 seconds
// Note: Green light does NOT override safety — this is the key test!

def spawn_crossing_pedestrians(world, blueprint_library, num_peds=3):
    """
    Spawn pedestrians walking across the intersection crosswalk.
    Uses CARLA's walker AI controller to follow a path.
    """
    ped_bps = blueprint_library.filter('walker.pedestrian.*')
    controller_bp = blueprint_library.find('controller.ai.walker')

    # Start positions on the west sidewalk, staggered
    start_positions = [
        carla.Transform(carla.Location(x=-6.0, y=0.5,  z=0.5)),
        carla.Transform(carla.Location(x=-6.0, y=-1.0, z=0.5)),
        carla.Transform(carla.Location(x=-6.0, y=-2.5, z=0.5)),
    ]

    # Cross to the east sidewalk (+x direction)
    goal_location = carla.Location(x=6.0, y=0.0, z=0.0)

    pedestrians   = []
    controllers   = []

    for i in range(num_peds):
        import random
        bp = random.choice(list(ped_bps))

        try:
            ped = world.spawn_actor(bp, start_positions[i])
            pedestrians.append(ped)
            print(f"[S4] Pedestrian {i+1} spawned at {start_positions[i].location}")
        except RuntimeError as e:
            print(f"[S4] Could not spawn pedestrian {i+1}: {e}")
            continue

    # Must tick world BEFORE starting controllers
    world.tick()

    for i, ped in enumerate(pedestrians):
        ctrl = world.spawn_actor(controller_bp, carla.Transform(), attach_to=ped)
        controllers.append(ctrl)

    world.tick()   # second tick to initialize controllers

    for i, ctrl in enumerate(controllers):
        ctrl.start()
        ctrl.go_to_location(goal_location)
        ctrl.set_max_speed(1.2 + i * 0.1)   # slightly different speeds
        print(f"[S4] Controller {i+1} walking toward ({goal_location.x}, {goal_location.y})")

    return pedestrians, controllers


def check_pedestrian_clear(world, crosswalk_x_range=(-5.0, 5.0), crosswalk_y_range=(-3.0, 3.0)):
    """
    Returns True if no pedestrian is currently in the crosswalk zone.
    Planner should only proceed when this returns True.
    """
    pedestrians = world.get_actors().filter('walker.pedestrian.*')

    for ped in pedestrians:
        loc = ped.get_location()
        in_crosswalk = (crosswalk_x_range[0] <= loc.x <= crosswalk_x_range[1] and
                        crosswalk_y_range[0] <= loc.y <= crosswalk_y_range[1])
        if in_crosswalk:
            return False, ped.get_location()

    return True, None


def compute_safety_robustness(ego_location, pedestrian_locations, safety_radius=2.0):
    """
    Computes P0 safety robustness: distance to nearest pedestrian minus safety radius.
    Negative value means P0 VIOLATED — planner failed.
    """
    if not pedestrian_locations:
        return 100.0   # No pedestrians — fully safe

    distances = [ego_location.distance(pl) for pl in pedestrian_locations]
    min_dist = min(distances)

    return min_dist - safety_radius   # positive = safe, negative = violation
TWTL Formulas
Formal specifications for all four scenarios — connecting Ahmad's research to Nidhi's planner
Operator Reference
Operator Symbol Meaning Driving Example
Hold Hd π Maintain condition π for d steps H₅ stopped = hold speed <0.5 m/s for 5 steps
Within [ φ ][a,b] Satisfy φ starting between time a and b [ H₂ at_stop ][0,10] = stop within 10s
Concatenation φ₁ · φ₂ Do φ₁ then immediately φ₂ stop · proceed = stop, then go
Conjunction φ₁ ∧ φ₂ Both hold simultaneously safe ∧ legal = safe AND following rules
Negation ¬φ Condition must NOT hold ¬collision = no collision ever

φ₂ = (d > d_stop → [ H₃ πstopped ][0,5]) ∧ (d ≤ d_stop → [ H₁ πthrough ][0,4]) ∧ HT ¬πred_violation
Correct stop-or-go decision; never runs a red light
Scenario 3 — Red, Waiting Traffic

Scenario 4 — Blocked + Pedestrians
φ₄ = HT ¬πped_collision ∧ [H₃ πped_clear][0,∞] · [H₁ πthrough][0,10] ∧ HT ¬πcollision

Predicate Definitions
Predicate Formal Definition Code Signal
πcollision { dmin | dmin < 0.5m } min LiDAR distance to obstacles
πped_collision { dped | dped < 2.0m } distance to nearest walker
πstopped { v | v < 0.5 m/s } ego velocity magnitude
πgreen_ok { state | light == GREEN } CARLA TrafficLightState enum
πred_entry { (loc, state) | in_intersection ∧ light == RED } intersection zone + light state
πped_clear { locped | locped ∉ crosswalk } no walkers in bounding box
πintersection { loc | loc ∈ junction_bbox } waypoint.is_junction == True
πthrough { loc | loc on far side of intersection } y > +5m past center
Robustness at a Glance

When to use ρ vs η

  • Use ρ (traditional) for Scenarios 1, 3, 4 — hard safety/legal constraints where worst-case matters
  • Use η (AGM) for Scenario 2 — smooth stop-or-go tradeoff benefits from a differentiable, optimistic measure
  • In both cases: positive value = specification satisfied; negative = violated
