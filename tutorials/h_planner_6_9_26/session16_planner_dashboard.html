Sampling + Hierarchical Planner
The planner generates N parameterized candidate trajectories, evaluates each against TWTL robustness measures (ρ for hard constraints, η for soft preferences), and filters them in three lexicographic stages before executing the best path.

Key insight:

P0 and P1 are evaluated with traditional ρ (min-based, worst-case). P2 uses AGM robustness η — smooth and differentiable, rewards trajectories where many time steps are strongly satisfying, not just the minimum.

Component 1
Sampling Trajectory Generator
Generates N candidate trajectories by varying two parameters: speed factor α (fraction of speed limit) and lateral offset β (meters from lane center). All paths follow CARLA's road network — no paths through buildings.
Speed Parameter α
Speed Factors
  • α = 0.0 — Full stop trajectory (emergency/red light)
  • α = 0.3 — Very slow (parking, pedestrian zone)
  • α = 0.5 — Half speed (cautious approach)
  • α = 0.7 — Moderate speed
  • α = 0.9 — Near speed limit
  • α = 1.0 — At speed limit

target_speed = α × speed_limit_ms

Lateral Parameter β
Lateral Offsets
  • β = −0.4m — Left of lane center
  • β = −0.2m — Slight left
  • β = 0.0m — Lane center (nominal)
  • β = +0.2m — Slight right
  • β = +0.4m — Right of lane center

6 × 5 = 30 candidate trajectories total

planner.py — SamplingTrajectoryGenerator.generate() PYTHON 
# Called once per replan cycle.  ego = current vehicle actor.
def generate(self, ego, speed_limit_ms):
    trajectories = []
    start_wp = self.carla_map.get_waypoint(ego.get_location())

    for alpha in self.SPEED_FACTORS:        # [0.0, 0.3, 0.5, 0.7, 0.9, 1.0]
        for beta in self.LATERAL_OFFSETS:   # [-0.4, -0.2, 0.0, 0.2, 0.4]

            # Walk road waypoints, shift laterally by beta
            traj = self._build_trajectory(start_wp, alpha, beta, speed_limit_ms)
            if traj:
                trajectories.append(traj)

    # Result: 30 Trajectory objects, each with .waypoints and .target_speeds
    return trajectories   # ready for TWTLEvaluator

# Lateral shift: perpendicular to lane direction
def _apply_lateral_offset(self, waypoint, offset):
    yaw_rad = math.radians(waypoint.transform.rotation.yaw)
    perp_x  = -math.sin(yaw_rad)   # perpendicular direction
    perp_y  =  math.cos(yaw_rad)
    loc     = waypoint.transform.location
    return carla.Location(
        x = loc.x + offset * perp_x,
        y = loc.y + offset * perp_y,
        z = loc.z
    )
Why lateral offset?

Small lateral variations let the planner naturally avoid obstacles that partially block a lane, or bias toward the lane center when a truck is close. The P0 filter removes trajectories where these offsets create unsafe proximity.

planner.py — ContextDetector.detect() PYTHON 
def detect(self, ego, carla_map, world):
    waypoint    = carla_map.get_waypoint(ego.get_location())
    speed_limit = ego.get_speed_limit()   # km/h from CARLA

    # Priority order — most specific first
    if self._is_at_or_approaching_intersection(waypoint):
        return Context.INTERSECTION        # check junction ahead (25m lookahead)
    elif speed_limit > 50.0:
        return Context.HIGHWAY
    elif speed_limit < 20.0:
        return Context.PARKING
    else:
        return Context.CITY                 # default

# Look ahead along road for junction within JUNCTION_LOOKAHEAD=25m
def _is_at_or_approaching_intersection(self, waypoint):
    if waypoint.is_junction:
        return True
    current = waypoint
    remaining = self.JUNCTION_LOOKAHEAD   # 25 metres
    while remaining > 0:
        nxt = current.next(3.0)
        if not nxt: break
        current = nxt[0]
        remaining -= 3.0
        if current.is_junction: return True
    return False
Component 3
Hierarchical Planner
Three lexicographically ordered stages. A trajectory only reaches Stage 2 if it passes Stage 1. The ordering guarantees safety is never sacrificed for speed or comfort.
Stage 1 — P0 (Safety)
Hard Safety Filter
  • Evaluate ρ_P0 for every trajectory
  • Keep only trajectories with ρ_P0 ≥ 0
  • ρ_P0 = min(d_obstacle − 1.5m, d_pedestrian − 2.5m)
  • If ALL fail → emergency brake
Stage 2 — P1 (Legal)
Legal Compliance Filter
  • Evaluate ρ_P1 on P0-surviving trajectories
  • Keep only trajectories with ρ_P1 ≥ 0
  • ρ_P1 = min(speed_margin, light_compliance)
  • If ALL fail → keep least-harmful P0 trajectory
Stage 3 — P2 (Soft)
Context-Aware Selection
  • Compute η_P2 for surviving trajectories
  • η uses AGM robustness (smooth, rewards margin)
  • Weights depend on detected context
  • Select argmax η_P2
P0 — Safety Robustness (traditional ρ)
ρ_P0 = mint∈trajectory min(d_obstacle(t) − 1.5m, d_pedestrian(t) − 2.5m)
// Worst-case minimum — if ANY point is unsafe, the whole trajectory is rejected
// ρ_P0 < 0 → trajectory filtered out (Stage 1)
P1 — Legal Robustness (traditional ρ)
ρ_P1 = min(v_limit + 1.5 − v_max, 1 if no_red_entry else −1)
// Speed margin: how far under the limit
// Red-light: −1 if trajectory enters junction while light is RED
// ρ_P1 < 0 → trajectory filtered out (Stage 2)
P2 — Soft AGM Robustness η (context-weighted)
η_P2 = w_comfort·comfort + w_efficiency·efficiency + w_safety·safety_margin
// comfort = 1 − |β| / max_offset (penalise large lateral deviation)
// efficiency = avg_speed / speed_limit (reward higher average speed)
// safety_margin = clip(ρ_P0 / 10, −1, 1) (normalised P0 headroom)
// Weights [w_comfort, w_efficiency, w_safety] depend on detected Context
planner.py — HierarchicalPlanner.plan() PYTHON 
def plan(self, ego, world, light, speed_limit_ms):

    # 0. Detect context (drives Stage 3 weights)
    context    = self.detector.detect(ego, self.carla_map, world)

    # 1. Sample N=30 candidate trajectories
    candidates = self.generator.generate(ego, speed_limit_ms)

    # 2. Evaluate ρ_P0, ρ_P1, η_P2 for each
    candidates = self.evaluator.evaluate_all(
        candidates, world, self.carla_map, light, speed_limit_ms, context
    )

    # Stage 1: P0 filter (safety — hardest constraint)
    p0_safe = [t for t in candidates if t.rho_p0 >= 0]
    if not p0_safe:
        return self._emergency_brake_trajectory(ego)   # ALL unsafe

    # Stage 2: P1 filter (legal compliance)
    p1_legal = [t for t in p0_safe if t.rho_p1 >= 0]
    if not p1_legal:
        p1_legal = [max(p0_safe, key=lambda t: t.rho_p1)]  # least harmful

    # Stage 3: P2 ranking (context-aware soft preferences)
    best = max(p1_legal, key=lambda t: t.eta_p2)

    return best   # → PathExecutor.set_trajectory(best)
Component 4
Path Executor
Converts the selected trajectory into CARLA VehicleControl commands every tick. Uses a proportional lateral controller for steering and a proportional speed controller for throttle/brake. Advances automatically to the next waypoint when within reach radius.
Lateral Control
Steering
  • Compute heading to next waypoint: atan2(dy, dx)
  • Compute yaw error vs current vehicle heading
  • steer = clip(Kp_steer × yaw_error, ±0.7)
  • Kp_steer = 0.6
  • Advance waypoint when distance < 3m
Longitudinal Control
Throttle / Brake
  • speed_error = target_speed − current_speed
  • If error ≥ 0: throttle = clip(Kp × error, 0, 0.8)
  • If error < 0: brake = clip(−Kp × 1.5 × error, 0, 1.0)
  • Kp_throttle = 0.5
  • α = 0.0 → target speed 0 → full brake
planner.py — PathExecutor.step() PYTHON 
# Called every simulation tick. Returns a carla.VehicleControl.
def step(self, ego):
    target_loc = self.current_traj.waypoints[self.current_wp_index]
    target_spd = self.current_traj.target_speeds[self.current_wp_index]

    ego_loc = ego.get_location()
    ego_yaw = math.radians(ego.get_transform().rotation.yaw)
    ego_spd = /* velocity magnitude */

    # Advance waypoint when close enough
    if ego_loc.distance(target_loc) < 3.0:
        self.current_wp_index += 1

    # Lateral: steer toward next waypoint
    yaw_error = atan2(dy, dx) - ego_yaw          # heading error
    steer     = clip(0.6 * yaw_error, -0.7, 0.7)

    # Longitudinal: proportional speed controller
    err = target_spd - ego_spd
    if err >= 0:
        throttle, brake = clip(0.5 * err, 0, 0.8), 0.0
    else:
        throttle, brake = 0.0, clip(-0.75 * err, 0, 1.0)

    return carla.VehicleControl(throttle=throttle, steer=steer, brake=brake)
Replan frequency:

The executor runs every tick (20 Hz). The planner reruns every REPLAN_INTERVAL=10 ticks (2 Hz). This means the executor follows the current best trajectory smoothly between replans, while the planner can react to changing conditions (new obstacles, light state change).

Putting it Together
Scenario Integration
The planning loop replaces ego.set_autopilot(True) in every scenario. The only thing that changes across scenarios is the light state and which actors are spawned — the planner handles everything else.
scenario_1_integrated.py — Main planning loop PYTHON 
# Instantiate planner components
planner  = HierarchicalPlanner(carla_map)
executor = PathExecutor()
logger   = RobustnessLogger("Scenario 1")

# Main tick loop (replaces ego.set_autopilot(True))
for tick in range(RUN_TICKS):
    world.tick()

    # ── Replan every 0.5s (10 ticks × 0.05s) ────────────────
    if tick % REPLAN_INTERVAL == 0:
        best = planner.plan(ego, world, light, speed_limit_ms)
        # best.rho_p0, best.rho_p1, best.eta_p2 all set
        executor.set_trajectory(best)

    # ── Execute one step ──────────────────────────────────────
    control = executor.step(ego)
    ego.apply_control(control)

    # ── Log robustness ────────────────────────────────────────
    logger.record(tick, tick * TICK_DELTA, best)

# Final TWTL robustness report (min ρ_P0, min ρ_P1, avg η_P2)
logger.report()

What the Planner Handles Automatically
Planner Adaptations
  • S1: Detects INTERSECTION ctx, picks comfort-first path at speed limit
  • S2: When light turns RED, P1 filter removes all junction-entering paths
  • S3: P0 filter keeps safe-distance paths; P1 filters out any red-entry
  • S4: P0 filter removes paths within 2.5m of pedestrians (overrides green light)
