🗺️ CARLA Road Network Guide

Understanding How CARLA Represents and Provides Road Information

Author: Ahmad Ahmad | For: Nidhi's Autonomous Driving Course

📚 Introduction

CARLA provides a sophisticated road network system that allows autonomous vehicles to navigate realistically. Instead of planning in free space (which would allow driving through buildings!), we use CARLA's waypoint system to stay on valid roads.

Why This Matters

When generating trajectories for autonomous vehicles, we need to ensure they follow actual roads. CARLA's road network API gives us:

  • Guaranteed on-road positions
  • Lane information and topology
  • Traffic rules and regulations
  • Safe navigation between points

1️⃣ The Map Object

The Map is CARLA's representation of the entire road network. Think of it as a digital twin of the road infrastructure.

# Get the map from the world world = client.get_world() carla_map = world.get_map() # Map name (e.g., 'Town01', 'Town02') print(carla_map.name) # Get spawn points (safe locations to spawn vehicles) spawn_points = carla_map.get_spawn_points() print(f"Available spawn points: {len(spawn_points)}") # Get topology (how roads connect) topology = carla_map.get_topology() print(f"Road segments: {len(topology)}")

The Map Contains:

  • Road Geometry: Lanes, curves, intersections, elevations
  • Road Topology: How road segments connect to each other
  • Traffic Rules: Speed limits, lane markings, right-of-way
  • Landmarks: Traffic lights, stop signs, crosswalks

2️⃣ Waypoints - The Core Concept ⭐

A waypoint is a directed point on a lane. This is THE fundamental building block of CARLA's road network.

# Convert any location to nearest point on a road vehicle_location = vehicle.get_location() waypoint = carla_map.get_waypoint(vehicle_location) # Waypoint contains rich information: print(waypoint.transform.location) # Position (x, y, z) print(waypoint.transform.rotation) # Direction lane is facing print(waypoint.road_id) # Which road print(waypoint.lane_id) # Which lane print(waypoint.lane_type) # Driving, Parking, Sidewalk print(waypoint.lane_width) # Width in meters print(waypoint.is_junction) # Is this an intersection?

Waypoint Properties

3️⃣ Navigating the Road Network

CARLA provides four key methods to navigate through the road network:

Method 1: next(distance) - Move Forward

next_waypoints = waypoint.next(10.0) # 10 meters ahead print(f"Waypoints ahead: {len(next_waypoints)}") # Returns LIST because road might split! for wp in next_waypoints: print(f"Option: Road {wp.road_id}, Lane {wp.lane_id}")

Returns: List of waypoints 10 meters ahead. Multiple waypoints if road branches (e.g., at intersection).

Method 2: previous(distance) - Move Backward

prev_waypoints = waypoint.previous(10.0) # 10 meters behind

Returns: List of waypoints 10 meters behind current position.

Method 3: get_left_lane() - Change to Left Lane

left_waypoint = waypoint.get_left_lane() if left_waypoint: print("Left lane exists!") print(f"Lane ID: {waypoint.lane_id} → {left_waypoint.lane_id}") else: print("No left lane (at road edge)")

Returns: Waypoint in the left lane (same position, different lane) or None if no left lane exists.

Method 4: get_right_lane() - Change to Right Lane

right_waypoint = waypoint.get_right_lane() if right_waypoint: print("Right lane exists!") else: print("No right lane (at road edge)")

Returns: Waypoint in the right lane or None if no right lane exists.

Navigation Visual

Current position: waypoint A next(5m) next(10m) A ────────→ B ────────────→ C │ │ get_left_lane() ↓ D (left lane, same position as A) At intersection: → Straight ↗ A ──┤ Turn Right ↘ → Turn Left

4️⃣ Generating Road-Following Paths

This is what we use for trajectory generation! The key is to repeatedly call next() to follow the road.

def generate_road_path(carla_map, start_location, distance=50.0): """Generate path that follows the road.""" # 1. Get starting waypoint ON THE ROAD current_waypoint = carla_map.get_waypoint(start_location) # 2. Build path by following road path = [current_waypoint.transform.location] for _ in range(25): # 25 steps # Get next waypoint 2 meters ahead next_waypoints = current_waypoint.next(2.0) if not next_waypoints: break # Road ended # Take first option (straight ahead) current_waypoint = next_waypoints[0] path.append(current_waypoint.transform.location) return path # List of (x,y,z) positions ON THE ROAD!

✅ What This Guarantees

All waypoints in the path are on valid roads. The path automatically follows:

  • Lane curvature and road geometry
  • Road topology and connections
  • Valid driving surfaces (no sidewalks or buildings!)

Path Generation Flow

Start ─2m→ wp1 ─2m→ wp2 ─2m→ wp3 ─2m→ ... ─2m→ End All waypoints guaranteed to be ON VALID ROADS! Path follows: ✓ Lane curvature ✓ Road topology ✓ Valid driving surfaces

5️⃣ Different Path Types

Using the same waypoint API, we can generate different maneuvers:

Straight Ahead

def straight_ahead(waypoint, distance=50): path = [] current = waypoint for _ in range(25): path.append(current.transform.location) next_wps = current.next(2.0) if next_wps: current = next_wps[0] # Take first (straight) return path

Lane Change Left

def lane_change_left(waypoint): path = [] current = waypoint # Go straight for 10m for _ in range(5): path.append(current.transform.location) current = current.next(2.0)[0] # Change to left lane left_lane = current.get_left_lane() if left_lane: current = left_lane # Continue in left lane for 20m for _ in range(10): path.append(current.transform.location) current = current.next(2.0)[0] return path

At Intersection

def at_intersection(waypoint): if waypoint.is_junction: # Get all possible directions options = waypoint.next(10.0) # Returns: [straight, turn_left, turn_right] # Each is a valid continuation! return options

6️⃣ Why This is Better Than Straight Lines

❌ Before (Straight Line)

# Linear interpolation for i in range(30): t = i / 29 x = start.x * (1-t) + goal.x * t y = start.y * (1-t) + goal.y * t

Result: Goes through buildings! 🏢💥

✅ After (Waypoint System)

# Follow road network current = map.get_waypoint(start) for _ in range(30): path.append(current.transform.location) current = current.next(2.0)[0]

Result: Stays on roads! 🛣️✅

7️⃣ Complete Example

Here's how to generate multiple trajectories using the road network:

# Connect to CARLA client = carla.Client('localhost', 2000) world = client.get_world() carla_map = world.get_map() # Get vehicle's current position vehicle_location = vehicle.get_location() start_waypoint = carla_map.get_waypoint(vehicle_location) # Generate Trajectory 1: Short straight (30m) traj1 = [] current = start_waypoint for _ in range(15): traj1.append(current.transform.location) next_wps = current.next(2.0) if next_wps: current = next_wps[0] # Generate Trajectory 2: Long straight (60m) traj2 = [] current = start_waypoint for _ in range(30): traj2.append(current.transform.location) next_wps = current.next(2.0) if next_wps: current = next_wps[0] # Generate Trajectory 3: Lane change left traj3 = [] current = start_waypoint for _ in range(5): traj3.append(current.transform.location) current = current.next(2.0)[0] # Change lanes! if current.get_left_lane(): current = current.get_left_lane() for _ in range(10): traj3.append(current.transform.location) current = current.next(2.0)[0] # All trajectories follow roads! No buildings! ✅

8️⃣ CARLA's Guarantees

The Waypoint System Guarantees:

  • All waypoints are on valid roads: get_waypoint() always snaps to the nearest road, never returns positions in buildings or sidewalks
  • next() only returns valid continuations: Returns empty list if road ends, multiple options if road splits
  • Lane changes only succeed if lane exists: get_left_lane() and get_right_lane() return None if no adjacent lane
  • Topology is consistent: Roads are properly connected with no gaps or discontinuities
  • Traffic rules are encoded: Lane markings, speed limits, and right-of-way information available

📝 Summary

The Road Network in CARLA: 1. MAP (world.get_map()) └─ Road geometry + topology + rules 2. WAYPOINT (map.get_waypoint(location)) └─ Directed point on lane └─ Contains: position, lane info, road info 3. NAVIGATION ├─ next(distance) → move forward ├─ previous(distance) → move backward ├─ get_left_lane() → change lanes └─ get_right_lane() → change lanes 4. PATH GENERATION └─ Start with waypoint └─ Use next() repeatedly └─ Result: Path following roads!

🎯 Key Takeaway

This is how we avoid buildings and stay on valid roads!

By using CARLA's waypoint system instead of straight-line interpolation, we guarantee that all generated trajectories follow legal, drivable paths. This is fundamental for realistic autonomous driving simulation.
